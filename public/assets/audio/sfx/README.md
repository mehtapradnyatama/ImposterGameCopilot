# IMPORTANT: Add your sound effect files here!

## Recommended Files:

### Essential SFX:
- **click.mp3** - Button click sound
- **hover.mp3** - Button hover sound (optional)
- **success.mp3** - Success action (vote submitted, game won)
- **error.mp3** - Error action
- **vote.mp3** - Vote submitted
- **game-start.mp3** - Game starts / voting starts
- **game-over.mp3** - Game ends / results screen

## Steps to Add:

1. Download sound effects (see sources below)
2. Place MP3 files here
3. Rename according to the list above

## Recommended Sources:
- Mixkit: https://mixkit.co/free-sound-effects/game/
- Zapsplat: https://www.zapsplat.com/sound-effect-categories/
- Freesound: https://freesound.org/ (need free account)

## Search Terms:
- "8-bit click"
- "arcade button"
- "retro game sound"
- "pixel sound effect"

## Tips:
- Keep each file under 500KB
- Duration: 0.1 - 1 second for clicks, 1-3 seconds for others
- Format: MP3, 128kbps
- No silence at start/end (trim in audio editor)
