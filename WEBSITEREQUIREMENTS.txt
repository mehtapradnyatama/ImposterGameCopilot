4. Gameplay Flow
Phase 1: Lobby (WAITING)

Show all joined players
Host controls "Start Game" button
Display room settings (timer, topic, max players)

Phase 2: Game Start (IN_PROGRESS)

System randomly selects 1 player as IMPOSTER
All normal players get the SAME word (randomly selected from chosen topic)
Imposter gets a card that says "IMPOSTER" (not the real word)
Each player sees their own word/role on screen
Start countdown timer based on room settings

Phase 3: Discussion (with Timer)

Countdown timer visible to all
Players use voice chat (Push-to-Talk) and text chat to discuss
Players try to find the imposter by asking questions
Timer shows warning at 10 seconds remaining (play sound effect)
When timer ends, move to voting phase

Phase 4: Voting

Each player votes for who they think is the imposter
Can't vote for yourself
Show voting UI with player avatars/names
Submit vote once
After all votes submitted OR 30-second timeout, show results

Phase 5: Results

Display voting results (who voted for whom)
Reveal who the actual imposter was
Award points:

If imposter NOT caught (didn't get majority votes): Imposter gets +2 points
If imposter caught: All normal players who voted correctly get +2 points
Losers get 0 points


Update leaderboard
Host can start new round or end game
